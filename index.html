Monte Carlo contingency simulation

An in-house Python tool that replaces a commercial add-in for setting project contingency. It simulates risk events and estimate uncertainty, then allocates the contingency back to individual risks and cost lines.

  • Python
  • NumPy / SciPy
  • pandas
  • PyQt6
  • matplotlib
  • Excel
Risk model
Each risk has a Bernoulli occurrence and a triangular or betaPERT cost impact.
Correlation
Gaussian copula with a Cholesky factor. Separate matrices for occurrence and impact. Matrices that are not positive semi-definite are repaired automatically.
Sampling
Latin Hypercube by default, basic random sampling optional. 10,000 iterations by default.
Estimate uncertainty
Ranges on each cost breakdown line (quantity, unit rate, labour hours and so on), correlated within and between lines.
Allocation
Contingency at a chosen percentile is split by each item's covariance with the project total, so the main drivers of variation get the most.
Interface
PyQt6 app to load data, edit correlation matrices, run the simulation and export a histogram and tornado chart to Excel.
Status
Distributions checked against @Risk. Latin Hypercube, probability ranging and allocation still need validation.
